# Mushaf Page Images

The reader expects 604 local WebP images:

- `001.webp` through `604.webp`
- Each filename contains the three-digit Mushaf page number.
- Verified dimensions: `1260 × 2038` pixels.

## Source status

The current files are a local technical-testing copy converted from:
`https://github.com/akram-seid/quran-hd-images`.

That repository does not provide an explicit redistribution or commercial-use license. These assets must not be treated as production-cleared until written permission or a verified open license is obtained from the rights holder.
